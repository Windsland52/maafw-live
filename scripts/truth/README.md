# 裁剪定标的人工真值（ground truth）

`survey:crop` 的「位置正确率」是**自洽**指标：模板在同帧上找得到自己就算对，哪怕框把整块背景
连元素一起裁进去。要算**漏报/误报**，就得有人先说出「这一帧上应该被找到的元素在哪」——
本目录放的就是这份外部标注。

## 文件

| 文件 | 数据集 | 说明 |
| :--- | :--- | :--- |
| `1999-720p.json` | 1999 主库的 0004–0007 帧（1280×720） | **种子集（6 个元素）**，只覆盖此前真机验证过、位置已被独立复核过的元素；要长 |

格式（`survey:crop --truth <file>` 消费，`scripts/survey-truth.mjs` 校验）：

```json
[{ "id": "0004", "label": "图鉴图标", "box": [71, 463, 57, 66], "frame": [1280, 720], "why": "…" }]
```

- `id`：**库内序号后四位**（与 `--cases`、`kf list` 的口径一致）。
- `box`：`[x, y, w, h]`，**该帧控制器分辨率空间**的像素坐标。
- `frame`：可选但建议写。标注所在的空间尺寸；与帧实际尺寸不符时脚本**拒绝打分**（不同空间比出来的
  误报全是假的），这是契约 §5 那条空间守卫在标注侧的同一件事。
- `why`：这条标注凭什么。种子集里每条都写了它与此前真机用框的差（差在哪、差多少）。

## 标注口径（改标注前先读）

1. **只标元素本身的墨迹范围**：文字类取字形亮于背景的像素包围盒，图形类取图形外描边。
   装饰线、英文副标题、角标（如 NEW 标签）**不计入**——它们不是"要被找到的那个元素"。
   涉及取舍的条目在 `why` 里写明排除了什么。
2. **框要贴合，不要"留余量"**：真值不是给裁剪用的输入框，而是判分基准。留余量会让宽松的裁剪
   结果也拿满分，指标就退回自洽了。
3. **量出来再写，不要估**：种子集里每个框都用像素级测量（亮度阈值求包围盒 + 放大图目视复核，
   边界 ±3px 内视为等价）。改一条标注就要在 `why` 里说清依据。
4. **帧变了就重标**：库帧重新采集（新 id、新分辨率）后旧标注不迁移——本目录按 `<游戏>-<短边>.json`
   分文件正是为此。

## 怎么复跑

```bash
npm run build
# 只用真值跑：每个元素按两档余量（每边 +6px / 长边的 25%）自动生成输入框，再按 IoU 判命中
node scripts/survey-crop.mjs --truth scripts/truth/1999-720p.json --out truth.json
# 真值 + 自定义输入框（比如沿用上一轮的 --cases 数据集）：两组数直接对比
node scripts/survey-crop.mjs --truth scripts/truth/1999-720p.json --cases cases.json --out truth-cases.json
```

输出里 `truth.recall` = 被某个最终框覆盖的真值比例（IoU ≥ `--truth-iou`，默认 0.5），
`truth.precision` = 不与任何真值框重叠的最终框比例；两个方向的另一种口径（`recallLoose` /
`precisionStrict`）与命中框的贴合度（`areaRatio`）一起报，用来分辨「没找到」「找到了但框很松」
「框落在没标注的空处」这三种不同的失分。口径定义在 `scripts/survey-truth.mjs` 头部，单测钉在
`test/unit-survey-truth.mjs`。

两条分母规则（不加区分就会把仪器的缺口记到工具头上）：

- **没有标注的帧不判分**：那里的最终框记 `unscored`，不进 precision 分母——没标注 ≠ 那里没有元素。
- **没有被任何输入框问到的真值不算漏报**：`--cases` 只跑一半元素、或网格恰好漏掉某个元素时，
  该元素记 `uncovered`、不进 recall 分母（精度侧照常参与：框压在它上面仍算找对了地方）。
  所以**读 recall 前先看 `truthsAsked`**：它才是分母。

## 加标注的流程

1. 选帧：`maafw-live kf list` 看库内留存帧，挑**真机验证过**的元素（位置已由屏幕状态或独立复核确认）
   ——真值错了，指标就全是噪声，而且不会有人发现。
2. 量框：解码该帧，用亮度阈值求元素墨迹的包围盒，再把框画回放大图目视复核（笔画顶部、右边缘最常被切）。
3. 写进对应数据集文件，`why` 里写清判据与排除项。
4. `node scripts/survey-crop.mjs --truth <file>` 复跑，确认新标注不会把已通过的条目打成漏报
   （真打成漏报也要先查是标注错了还是裁剪真的错了）。
